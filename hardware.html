Our Hardware Teams

UAV Drone Racing

Engineer high-speed, custom-built UAVs that compete in competitions and drone racing! Learn to master UAV flight by integrating separate hardware components, tuning flight dynamics, and earning a flying certification.

Robotic Arm

Design a robotic arm that executes complex tasks using custom electronics and machine learning. Learn how to build hardware systems by integrating mechanical structures, wiring electronics, and programming software algorithms.

Mars Rover

Build an off-road rover that tackles simulated Martian terrain and missions using robust systems engineering. Learn how to fabricate mechanical parts, design power systems, and implement autonomous navigation.

Autonomous Maze Solving Robot

Build autonomous rovers that detect and avoid obstacles to navigate a timed maze challenge using embedded systems. Learn how to make robots by wiring sensors, controlling motors, and writing decision-making code.
